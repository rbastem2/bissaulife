# BissauLife

App guia e marketplace da Guine-Bissau.

## Como compilar

1. Faz git push para a branch main
2. Vai em Actions no GitHub
3. Espera o workflow "Build APK" terminar
4. Baixa o APK em Artifacts > BissauLife-APK
5. Instala no celular
